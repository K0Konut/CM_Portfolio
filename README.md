# CM_Portfolio

Portfolio personnel de Costa Maskulov.

## Documentation principale

- `Docs/PRD.md` : cadrage produit et pages principales.
- `Docs/Integration_Plan_V1.md` : plan de passage des maquettes au code.
- `Docs/Motion_Spec_V1.md` : spec des animations a integrer en code.
- `Docs/Design_System_Foundations.md` : fondations visuelles.
- `Docs/Components_Specs/` : specs des composants.
- `Suivis_de_Projet/Suivi_Portfolio.md` : etat reel du projet et reprise.

## Stack cible

```txt
Vue 3
Vite
TypeScript
Vue Router
CSS natif organise par tokens
```
