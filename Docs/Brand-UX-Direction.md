# Brand & UX Direction — Portfolio Costa Maskulov

Ce document définit le territoire de marque, le positionnement, le ton, les principes UX et la direction artistique du portfolio de Costa Maskulov.

## 1. Territoire de marque

### Creative Full-Stack Playground

Le portfolio de Costa Maskulov est pensé comme une expérience web créative, moderne et interactive, qui montre autant sa personnalité visuelle que sa maîtrise technique.

Ce n'est pas un simple CV en ligne. C'est un espace digital qui doit prouver que Costa sait concevoir, structurer et développer des interfaces vivantes, originales et maintenables.

---

## 2. Positionnement

Costa est un développeur full-stack créatif, avec une forte sensibilité UI/UX, capable de créer des interfaces modernes, dynamiques et professionnelles.

L'image à transmettre :

> Costa est un développeur créatif, sérieux techniquement, capable de réaliser des interfaces modernes et originales.

Le portfolio doit se rapprocher de l'univers d'un studio digital créatif, tout en gardant la clarté nécessaire pour présenter :

* ses projets ;
* son parcours ;
* ses compétences ;
* sa méthode ;
* son profil professionnel ;
* ses moyens de contact.

---

## 3. Niveau de direction artistique

Le niveau choisi est :

### Niveau 2 — Créatif assumé mais maîtrisé

Cela implique :

* une identité visuelle forte ;
* des animations visibles ;
* des interactions modernes ;
* des layouts moins classiques ;
* une vraie personnalité graphique ;
* une navigation claire ;
* une lecture simple ;
* une présentation professionnelle.

Le site ne doit pas devenir trop expérimental au point de perdre le visiteur.

**Règle directrice :**

> Le portfolio doit surprendre sans désorienter.

---

## 4. Phrase manifeste

La phrase centrale du portfolio est :

> Développeur full-stack, je transforme des idées en interfaces vivantes, créatives et maintenables.

Cette phrase équilibre les trois dimensions importantes du positionnement :

### Idées

Costa ne fait pas seulement du code : il part d'un besoin ou d'un concept.

### Interfaces vivantes et créatives

La formulation met en avant sa sensibilité pour l'UI, le motion design, l'interaction et l'expérience web.

### Maintenables

Elle montre que derrière la créativité se trouve une vraie rigueur technique.

---

## 5. Ton de voix

Le ton doit être humain, clair, créatif et professionnel.

Il faut éviter un ton trop corporate, comme :

> Passionné par les nouvelles technologies, je suis motivé...

Il faut également éviter un ton arrogant ou excessivement « agence hype ».

Le ton recherché ressemble plutôt à :

> J'aime créer des interfaces qui ont du caractère, avec une structure propre derrière.

Ou :

> Je conçois des expériences web modernes, lisibles et vivantes, pensées autant pour l'utilisateur que pour le code.

L'écriture doit être :

* simple ;
* directe ;
* personnelle ;
* professionnelle ;
* légèrement créative ;
* jamais trop froide.

---

## 6. Piliers d'identité

L'identité du portfolio repose sur quatre piliers.

### Créatif

Le portfolio doit avoir une vraie personnalité et ne pas ressembler à un template de développeur classique.

Conséquences :

* direction artistique forte ;
* cards originales ;
* animations ;
* couleurs expressives ;
* titres plus vivants ;
* détails graphiques mémorables.

### Technique

Le visiteur doit comprendre que Costa sait coder proprement.

Conséquences :

* projets bien structurés ;
* stack visible ;
* architecture claire ;
* détails techniques dans les pages projets ;
* code maintenable ;
* design system modulaire.

### Interactif

L'expérience doit être vivante.

Conséquences :

* hovers animés ;
* apparitions au scroll ;
* transitions entre sections ;
* project cards dynamiques ;
* micro-interactions sur les boutons, tags et liens.

### Lisible et accessible

Même avec une direction artistique forte, le site doit rester compréhensible.

Conséquences :

* navigation simple ;
* textes courts ;
* hiérarchie claire ;
* bon contraste ;
* responsive propre ;
* animations non bloquantes ;
* respect de `prefers-reduced-motion`.

---

## 7. Principes UX

### Le visiteur doit comprendre rapidement qui est Costa

En quelques secondes, il doit comprendre :

> Costa Maskulov — développeur full-stack créatif — capable de créer des interfaces modernes et maintenables.

### Les projets doivent rester au centre

Même si le site est créatif, il ne doit pas devenir une démonstration d'animations vide.

Le portfolio doit avant tout montrer :

* ce que Costa a fait ;
* pourquoi il l'a fait ;
* comment il l'a fait ;
* avec quelles technologies ;
* ce que cela prouve de son niveau.

### La navigation doit rester simple

Même si la direction artistique est originale, la structure reste claire :

* Accueil ;
* Projets ;
* À propos ;
* Contact.

Ces sections peuvent être visuellement originales, mais elles ne doivent pas être cachées.

### Chaque animation doit avoir un rôle

Une animation peut servir à :

* guider le regard ;
* révéler une information ;
* créer du rythme ;
* rendre une interaction plus agréable ;
* renforcer l'identité.

Elle ne doit jamais ralentir ou gêner l'expérience.

**Règle validée :**

> Le mouvement doit donner de l'énergie, pas ralentir la lecture.

---

## 8. Principes motion

Le motion system doit inclure :

* des animations au scroll ;
* des hovers sur les cards projets ;
* des transitions entre les pages ;
* l'apparition animée des titres ;
* des stickers ou éléments flottants ;
* des micro-interactions.

Le custom cursor est volontairement exclu. Il peut rapidement devenir gadget, lourd ou gênant, particulièrement sur un portfolio professionnel.

### Scroll reveal

Les sections apparaissent progressivement.

### Hover expressif

Les cards, boutons et projets réagissent au passage de la souris.

### Transitions fluides

Les changements de page ou de section sont doux.

### Éléments graphiques vivants

Les stickers, formes, badges et visuels peuvent bouger légèrement pour donner de l'énergie.

---

## 9. Architecture des pages

### Accueil

**Rôle :** donner envie, présenter l'univers du portfolio et montrer rapidement qui est Costa.

Contenu probable :

* hero manifeste ;
* phrase d'introduction ;
* projets mis en avant ;
* aperçu de la stack ;
* mini-section à propos ;
* CTA de contact.

### Projets

**Rôle :** montrer le travail réalisé de manière claire et visuelle.

Contenu probable :

* grille de projets ;
* filtres éventuels ;
* project cards ;
* tags de stack ;
* statut du projet ;
* lien vers le détail.

### Détail projet

**Rôle :** prouver la démarche et le niveau technique.

Contenu probable :

* contexte ;
* objectif ;
* rôle personnel ;
* stack ;
* fonctionnalités ;
* architecture ;
* captures ;
* difficultés ;
* apprentissages ;
* liens GitHub et démo.

### À propos

**Rôle :** présenter le parcours, la personnalité et la vision du développement.

Contenu probable :

* courte présentation ;
* parcours ;
* compétences ;
* méthode de travail ;
* outils ;
* valeurs ;
* CV.

### Contact

**Rôle :** permettre une prise de contact simple.

Contenu probable :

* e-mail ;
* LinkedIn ;
* GitHub ;
* CV ;
* message court et humain.

## 11. Direction résumée

> Créer un portfolio de développeur full-stack qui ressemble à un mini studio digital personnel : créatif, vivant, professionnel, techniquement sérieux et mémorable.

> Un portfolio expressif mais clair, où la créativité sert la présentation du profil et des projets.
